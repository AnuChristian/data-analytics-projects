Project: User Engagement Analysis Dashboard

Description:
This project focuses on cleaning and analysing user engagement data from a distance learning platform. The goal was to develop a parent-facing dashboard that allows parents to track their child’s progress and performance.

Tools Used:

SQL
Power BI
Excel

Key Features:

Data cleaning and transformation to ensure data accuracy
KPI tracking including user activity and goal completion
Dashboard design for non-technical stakeholders (parents)
Insights to support data-driven decision making

Files Included:

SQL database file
Project report
Dashboard
